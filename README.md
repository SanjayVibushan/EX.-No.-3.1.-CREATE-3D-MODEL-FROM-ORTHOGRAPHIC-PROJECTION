# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION

## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1. Open Autodesk Fusion 360, create a new design and select the top view plane to start the sketch.<img width="1920" height="885" alt="Screenshot (98)" src="https://github.com/user-attachments/assets/e5656b7d-fc83-4ccd-be7d-808787337c21" />

2. Select the Line tool from the Create menu and draw the initial sketch profile as shown in the screenshot.<img width="1920" height="874" alt="Screenshot (100)" src="https://github.com/user-attachments/assets/08f87485-8ca3-4075-b369-0e21ccea3429" />

3. Apply the dimensions 52 mm for the overall length, 41 mm for the inner length, 11 mm for the upper and lower portions, and 18 mm for the inner spacing.<img width="1920" height="881" alt="Screenshot (101)" src="https://github.com/user-attachments/assets/42011980-86e4-4999-80f1-12abbd454f07" />

4. Click Finish Sketch and select the required profile. Choose Extrude from the Solid menu.
5. Enter an extrusion distance of 32 mm, select New Body and click OK.<img width="1920" height="875" alt="Screenshot (102)" src="https://github.com/user-attachments/assets/8a262344-46b6-4d36-9d77-a8cfbc33bff8" />

6. Select the right-side vertical face of the created body and click Create Sketch.<img width="1920" height="884" alt="Screenshot (103)" src="https://github.com/user-attachments/assets/e6eac372-4275-4566-9986-a7c7003772c5" />

7. Select the Circle tool and draw a circle of diameter 18 mm. Position its centre at 25 mm from the reference edge.<img width="1920" height="875" alt="Screenshot (104)" src="https://github.com/user-attachments/assets/c64da9f2-1427-46b3-85ef-e24d1a2e6fda" />

8. Click Finish Sketch, select the circular profile and choose Extrude.
9. Enter an extrusion distance of 32 mm and select the Join option to create the cylindrical projection.<img width="1920" height="885" alt="Screenshot (105)" src="https://github.com/user-attachments/assets/77e842bb-be16-4ef0-8390-82b5ba29cf0f" />

10. Select the front vertical face of the model and create a new sketch.<img width="1920" height="890" alt="Screenshot (106)" src="https://github.com/user-attachments/assets/7b75b823-b5fd-4fe1-b719-b8c13f1dc88b" />

11. Select the Circle tool and draw a circle of diameter 16 mm. Position it using a horizontal dimension of 36 mm from the reference edge.<img width="1920" height="888" alt="Screenshot (108)" src="https://github.com/user-attachments/assets/7d9942f2-5149-411b-99a1-53b20e95f973" />

12. Click Finish Sketch, select the circular profile and choose Extrude.
13. Select the Cut operation and enter an extrusion distance such that it creates the circular hole.<img width="1920" height="885" alt="Screenshot (109)" src="https://github.com/user-attachments/assets/f83e37b6-291e-4802-a490-ce98c9f51ef4" />

14. Select Fillet from the Modify menu in the Solid workspace.
15. Select the four edges shown in the final screenshot and apply a constant fillet radius of 16 mm. Keep the Tangent Chain option enabled.<img width="1920" height="888" alt="Screenshot (111)" src="https://github.com/user-attachments/assets/8d3e06be-03b0-48d6-8446-3539dc11361f" />

16. Click OK to complete the fillet operation and save the final 3D model.
17. Save the part design and create a new drawing from the File menu. Draw the necessary dimensions and views, and save the drawing.
